## 対象シート

**ドメイン／GSC／GA／Workspace 設定依頼管理**スプレッドシートを使用します。
サイト制作完了後に発生する各種設定作業の依頼・進捗・完了を一元管理するためのシートです。

スプレッドシートURL: https://docs.google.com/spreadsheets/d/{DOMAIN_REQUEST_SHEET_ID}/

---

## シートの基本構造

### シート一覧

本スプレッドシートは以下の7シートで構成されています。

| # | シート名 | 列数 | 用途 |
| --- | --- | --- | --- |
| 1 | ドメイン接続依頼 | 14列 | ドメイン接続の依頼・進捗管理 |
| 2 | 先方アドレスGSC権限依頼 | 10列 | Google Search Console 権限付与の管理 |
| 3 | 先方アドレスGA接続依頼 | 11列 | Google Analytics 接続の管理 |
| 4 | 先方アドレスClarity接続依頼 | 11列 | Microsoft Clarity 接続の管理 |
| 5 | Google Workspace作成依頼 | 15列 | Google Workspace アカウント作成の管理 |
| 6 | マスターデータ | 7列 | ドロップダウン選択肢の定義 |
| 7 | _meta | 8列 | 全カラムの定義情報（システム用） |

### 共通ルール

- **1行目**はシステム用のsnake_case名称です（グレー文字）。入力不要です。
- **2行目**が日本語ヘッダーです。
- **3行目以降**がデータ行です。
- ドロップダウン列はプルダウンから選択してください。直接入力すると選択肢外の値が入り、管理に支障をきたします。
- **完了日列は自動入力**です。ステータスが完了値になると自動でその日の日付が入ります。手動入力は不要です。

### 色の見方

| 背景色 | グループ | 意味 |
| --- | --- | --- |
| 青系（#DCE6F1） | 案件情報 | 案件の基本情報（顧客ID・パートナー名等） |
| オレンジ系（#FCE5CD） | 先方確認 / Workspace設定 | 先方から取得する情報・設定内容 |

| グレー系（#F3F3F3） | その他 | 備考 |

#### ドメイン区分による入力の違い

| ドメイン区分 | H列〜J列（先方ドメイン情報） |
| --- | --- |
| 先方ドメイン接続 | **入力必須** — 先方のドメインサービス名・ID・PWを記入 |
| 弊社ドメイン取得（確保済） | **入力不要** — H〜J列はグレーアウト表示 |
| 弊社ドメイン取得（新規） | **入力不要** — H〜J列はグレーアウト表示 |

> ドメイン区分が「弊社ドメイン取得」の場合、H・I・J列は自動的にグレーアウトされます。先方のドメインサービス情報は不要です。

#### ドメイン接続ステータスの遷移

| # | ステータス | 説明 |
| --- | --- | --- |
| 1 | 未着手 | 依頼を受けたが未対応 |
| 2 | ドメイン接続依頼中 | 先方にドメイン接続を依頼中 |
| 3 | 先方ドメイン接続中（先方接続） | 先方がドメインの設定を行っている段階 |
| 4 | 先方ドメイン確認中 | 接続設定後、先方に確認を依頼している段階 |
| 5 | ドメイン接続完了 | 接続完了（完了日が自動入力される） |

> **先方接続の場合のAレコード・CNAMEの取得手順**は [08-先方接続時のVercel-Aレコード-CNAME取得.md](08-先方接続時のVercel-Aレコード-CNAME取得.md) を参照してください。
> **サブドメイン（www等）で接続する場合は、Vercel上にAレコードが表示されずCNAMEのみが表示されます。それが正常な状態**なので、CNAMEだけを先方に案内すれば問題ありません。

## 運用手順

### 依頼の登録

1. 該当するシートを開く（ドメイン / GSC / GA / Clarity / Workspace）
2. A〜C列（顧客ID・レコード番号・パートナー名）はKintone連携により自動入力されます。
3. D列（依頼者氏名）にプルダウンから自分の名前を選択する
4. E列（担当者氏名）にプルダウンから担当者を選択する
5. 各シート固有の情報列（先方確認 / Workspace設定）を埋める

### 作業の完了

1. ステータス列をプルダウンから「完了」（またはドメインの場合は「ドメイン接続完了」）に変更する
2. 完了日が自動入力されることを確認する
3. 先方への報告が完了したら、先方報告完了 / 先方共有完了にチェック（✓）を入れる

> **完了日列は触らないでください。** ステータスが完了値に変更されると、数式で自動的にその日の日付が入ります。手動で入力・上書きすると数式が壊れます。

## 自動入力の仕組み

各シートのA〜C列（顧客ID・レコード番号・パートナー名）は、制作進行シートと連動して自動転記されます。シートによってトリガーが異なります。

制作進行シートURL: https://docs.google.com/spreadsheets/d/1OfNcHbWvRIYyMEy9bSU4-aCduL0rmdw_fVQla9Fa8Dc/

| 対象シート | トリガー |
| --- | --- |
| ドメイン接続依頼 | 制作進行シートのメインにデータが追加された時点 |
| Google Workspace作成依頼 | 制作進行シートのメインにデータが追加された時点 |
| GSC権限依頼 | 制作進行シートのメインの完了日（`completion_date` = **AV列**）に日付が記載された時点 |
| GA接続依頼 | 制作進行シートのメインの完了日（`completion_date` = **AV列**）に日付が記載された時点 |
| Clarity接続依頼 | 制作進行シートのメインの完了日（`completion_date` = **AV列**）に日付が記載された時点 |

> いずれのシートもA〜C列は手動入力不要です。ドメイン接続とWorkspaceは案件登録時、GSC・GA・Clarityはサイト制作完了時に自動転記されます。
> 移管前のNotion原本では完了日を「O列」と記載していましたが、これは旧列レイアウト時代の表記です。現行49列レイアウトでは **AV列**（`completion_date`）が完了日で、転記処理（[gas/GSCGAWORK.js](../../gas/GSCGAWORK.js)）はヘッダー名 `completion_date` で列を探すため、列位置が変わっても動作します。

## 注意事項

- **_metaシートは編集禁止です。** カラム定義が記録されており、システム連携やメンテナンスに使用します。
- 各シートの **1行目（snake_case行）は編集禁止**です。Kintone連携やGAS処理の識別子として使用しています。
- 日付は **yyyy/mm/dd** 形式で入力してください。
- セキュリティ上の注意: **ドメインサービスのID・PW列（I列・J列）** には機密情報が含まれます。シートの共有範囲に十分注意してください。
