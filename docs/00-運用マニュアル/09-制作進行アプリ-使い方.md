## 2. 盤（トップ画面）― 自分の番の案件を見つける

| 見るところ | 意味 |
|---|---|
| 上の帯「起票 → 制作 → 運用」 | 全体の流れ |
| 制作の 7 列 | 左から「ヒアリング → デモ制作 → 初校チェック → 提出・顧客確認 → 修正 → ドメイン接続 → 公開・納品」。旧シートの M 列の状態がどの段かで並びます |
| 青い枠・「あなたの番」 | いま自分が動く案件。「N 日」はその段に入ってからの日数。赤い日付は期限超過 |

| 運用 / 止まっている | 帯の「運用」= 旧シートの完了タブ。「止まっている」= 長期未返信・未払い停止・制作中解約。押すと一覧が開きます |
| カードを押す | 案件の画面が開きます（4.） |

## 3. 検索 ― 番号かパートナー名で探す

- 右上の検索欄。番号（kintone のレコード番号）は完全一致、パートナー名は一部でも可。
- 制作・運用・止まっているの全区分を横断します。旧シートのどのタブにある案件でも（完了・解約・長期未返信も）、ここから 1 回で見つかります。

## 4. 案件の画面 ― 上から順に読む

| 場所 | 内容 |
|---|---|
| 見出し | 番号・パートナー名・プラン・「あなたの番」（他の人の番なら「◯◯ の番」）・期限。期限の赤字は遅延日数 |
| レール | 起票から運用までの 9 段。塗りつぶしが済んだ段、枠付きがいまの段。各段に入った日付が出ます |
| いまの段 | 青い帯に「あなたの番です ― やること」。その下に、この段で記録する項目とボタン |
| 右の枠 | 注意メモ・契約（kintone から同期。ここでは変えられません）・担当（ディレクター／ポリッシュ／Wix／営業）・各リンク（テストサイト・本番・アノテーター・ヒアリングシートなど）・**ドメインと通知**（6.） |
| できごと | 画面の一番下。起票から今までの状態の変化・担当の変更・値の変更を、誰が・いつ、の順で記録。シートの変更履歴の代わり |

## 5. ディレクターが押すボタン ― シートの M 列の代わり

状態はボタンで進めます。ボタンの文字に「次に誰へ渡るか」が書いてあります。ボタンは「今の状態 × 自分の役割」で出るので、他の人の番のときは出ません。

### 初校チェック（状態: デモサイト制作完了）

- PC とスマホで初校を見て、7 観点に OK / NG を記録します。PC とスマホの 2 つが今回のチェックで OK になるまで「チェック完了」は押せません。
- チェック項目の下の「チェック完了 → 営業へ渡す」か「大幅修正で差し戻す（ポリッシュへ）」（理由を書く）。

### 顧客 OK のあと（状態: 修正サイト提出済み）

- 顧客の番のあいだも開けます。顧客の OK が取れたら「顧客 OK → ドメイン接続へ進める」。

### 確認待ち（ポリッシュからの確認依頼）

- ポリッシュが「確認依頼を出す」と、その案件にピンクの「確認待ち」が付き、ボールがディレクターに移ります。
- 案件の画面の「確認依頼」で回答すると、ポリッシュに戻ります。

### 公開・納品（状態: 公開）

- 納品チェックを上から順に（インデックス → フォーム → リンク・favicon → ドメイン → Google・本番 URL → PA → 納品連絡 → 完了処理）。
- 必須がそろった瞬間に自動で「完了」になり、運用へ移ります（シートと同じ規則）。「完了にする → 運用へ」を押すのは、そろっているのに進行中のまま残った案件だけ。
- 足りないまま完了にするときは「例外として完了にする」（理由が必須。できごとに残ります）。
- 納品連絡の文面はこの画面で作れます（送るのは Desk から）。

## 6. ボタンに無い直し

### 「状態・区分・担当・期限を直接変える」

案件の画面の「いまの段」の下にある「▸ 状態・区分・担当・期限を直接変える」を開くと、流れの表に無い直しができます（ディレクターと管理者だけ）。変えた値と理由は「できごと」に残ります。

| 操作 | 内容 |
|---|---|
| 状態を変える | 12 種類（Wix の案件は N 列の状態）から選ぶ。シートの M 列・N 列を手で書き換えていた操作に当たります |
| 区分を手で変える | メイン以外（長期未返信・未払い停止・制作中解約）に動かす。理由を書く。手で変えた案件は毎日の自動の判定から外れます（メインに戻すと判定に戻る） |
| 期限を手で変える | 理由を書く。顧客に事前連絡した場合はチェック |
| 担当を交代する | ディレクター／ポリッシュ／Wix を選び直す。交代の理由は履歴に残る。画面で交代した担当は kintone には送りません |

### 右の枠「ドメインと通知」

| 項目 | 内容 |
|---|---|
| ヒアリングシート URL | 表示と「書き直す」。**再制作**は、URL を差し替えて「直接変える」で状態を「デモサイト制作中」に戻せば bot が拾います |
| Push 通知 | 「送る / 除外」を表示。理由を書いて止める・戻す（旧 push_exclude 列） |
| ドメイン接続ステータス | 「手で変える」で選ぶ（PS・ディレクター。旧 AQ 列）。ほかに Launch Console・Desk の自動返信・納品チェックが書く。**設定依頼管理シートの K 列を変えてもアプリには反映されません** |
| ドメイン接続希望 | 「書き直す」（PS・ディレクター。旧 AW 列） |

変えた値は全部「できごと」に残ります。

## 7. 人がやらなくてよくなること（アプリが自動でやる）

| 今までの手作業 | アプリ |
|---|---|
| 行の起票 | kintone で契約が J になると 15 分以内に案件が作られます |
| 期限（旧 T 列） | 状態を進めるとアプリが営業日で期限を張ります。ドメイン接続ステータスが「ドメイン接続方法確認中」「先方ドメイン接続中（先方接続）」「先方ドメイン確認中」に変わったときも、メインの案件なら今日 + 2 営業日を張ります |
| 区分（旧タブ間の移動） | 完了・解約・長期未返信・未払い停止・復帰の判定は毎日アプリが行います |
| 担当ディレクターの振り分け | 新しい案件は名簿の重みで自動で割り振られ、kintone にも書き戻します |
| 設定依頼管理シートへの転記 | ドメイン接続依頼・GTM など 6 タブへの行追加は毎時アプリが行います |
| Slack 通知 | 遅延の警告・スマートSEO への連絡はアプリから出ます |

## 8. シートの操作 → アプリの操作

ほかのマニュアルの手順をアプリで行うときの読み替えです。

| シートでしていたこと | アプリでは |
|---|---|
| M 列（統合ステータス）を進める | 案件の画面のボタン（5.）。ボタンに無いときは「直接変える」の「状態を変える」 |
| N 列（Wix のステータス）を変える | 「直接変える」の「状態を変える」（Wix の状態が出ます） |
| I 列（担当ディレクター）などの担当を変える | 「直接変える」の「担当を交代する」（kintone には送らない） |
| T 列（フェーズ期限日）を書く | 自動（7.）。直すときは「直接変える」の「期限を手で変える」 |
| 行を別のタブ（長期未返信・未払い停止・制作中解約）へ移す | 「直接変える」の「区分を手で変える」 |
| AQ 列（ドメイン接続ステータス）を書く | 右の枠「ドメインと通知」の「手で変える」（設定依頼管理シートの K 列からは反映されない） |
| AW 列（ドメイン接続希望）を書く | 右の枠「ドメインと通知」の「書き直す」 |
| 既存サイト修正の再修正（黄色行で一番上に追記） | 修正依頼を開いて「再修正として戻す」（理由必須。一番上に「再修正・2 営業日以内」で出る。[01 PS 12-2](01-PS運用マニュアル.md#12-2-対応区分再修正--新規依頼)） |
| ヒアリングシート URL を差し替える | 右の枠「ドメインと通知」の「書き直す」 |
| push_exclude（Push 除外）を付ける・外す | 右の枠「ドメインと通知」の Push 通知 |
| 新しい行を起票する | 不要（kintone が J になると自動で作られる） |
| 完了タブへ移す | 不要（納品チェックがそろうと自動で完了） |
| 既存サイト修正シートを見る・行を足す | 案件を開いて「運用」の段。既存サイト修正シートの行はアプリに移っています |
| シートの変更履歴を見る | 案件の画面の一番下「できごと」 |

## 9. よくある疑問

| 疑問 | 答え |
|---|---|
| シートに書いてしまった | 切替後のシートは編集できません。もし書けても反映されないので、アプリで同じ操作をしてください |
| 案件が見つからない | 検索欄で番号を探す（完了・解約も出ます）。無ければ番号を添えて切替スレッドへ |
| ボタンが出ない | 自分の番でない（見出しの「◯◯ の番」を見る）か、役割が違います。急ぐなら「直接変える」 |
| Wix の案件 | 同じアプリ。Wix の状態（旧 N 列）がそのまま出ます |
| AI サイトエディター・修正ツール（アノテーター） | 裏でアプリを読むように切り替わっています。使い方は同じ。「修正開始」「修正完了」「完了報告」はアプリに記録されます（2026-10-23 13:45 以降） |
| 自動返信（Desk） | ドメイン接続ステータスなどはアプリを読み書きしています（2026-10-23 13:45 以降） |
| 困ったとき・おかしいとき | Slack #products-dev-リーダー窓口-freedev の切替スレッドに、番号と画面の状況（スクリーンショット可）を書いてください |
